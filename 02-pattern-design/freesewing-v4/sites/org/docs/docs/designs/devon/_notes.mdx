I Designed Devon because I had a nice denim jacket that I wanted to make
available to others.

Devon is based on the Bent body block. Being a jacket, it has a
considerable amount of ease added.

The design is inspired by denim jackets my partner has, and some
patterns I've seen. Most denim jackets do not have set in sleeves,
but since this is based on Bent, it does. It makes top stitching the
armscye a little more challenging.
