## What You Need {#needs}

To make Sunny, you will need the following:

- [Basic sewing supplies](/docs/sewing/basic-sewing-supplies)
- Several meters (~3x the waist) of a suitable main fabric (see [Fabric
  Options](#fabric))
- Enough ribbon to tie around the waist twice (if using)

## Fabric Options {#fabric}

### Main Fabric

This skirt is extremely versatile; nearly any woven fabric will work. As a petticoat, a light fabric that's comfortable
against the skin is best. For an overskirt, a more durable fabric, such as a medium weight linen, is preferred. In general, the longer the skirt, the more the fabric should flow (e.g., a stiffer fabric for a mini skirt, light/medium wool for an ankle length skirt).

## Cutting Instructions {#cutting}

**Main Fabric**

- Cut two skirt panels.
- Cut two waistbands (fabric or ribbon).
